МАЛЫШИ — ТАМАГОЧИ v1.1
1. Создайте отдельный публичный репозиторий GitHub: tamagotchi.
2. Загрузите все распакованные файлы в корень репозитория (не ZIP).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Откройте опубликованный адрес через Safari. Поделиться → На экран «Домой».
5. После первой успешной загрузки и регистрации service worker игра может работать офлайн.
Прогресс каждого питомца хранится локально. Время ухода рассчитывается по часам устройства даже после закрытия. Питомцы не умирают. Уведомлений при закрытом приложении нет. Очистка данных сайта может удалить сохранения.

Питомцы: чёрный лабрадор, коричневый чихуахуа, чёрно-белый котик. Использованы три предоставленные иллюстрации с фонами. Старые сохранения совместимы на том же адресе: виды и стандартные имена заменены, пользовательские имена и характеристики сохранены. Для обновления загрузите все файлы в существующий репозиторий и перезапустите игру онлайн.
